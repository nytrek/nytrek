I focus on offensive security: figuring out how real systems break, then writing
up the root cause and the fix. I keep a public set of CTF and lab writeups and
I'm working toward cloud security and red teaming.

### Currently

- Building [**security-writeups**](https://github.com/nytrek/security-writeups): source-level walkthroughs of CTF rooms and vulnerable labs (web, AI, networking), each one with root cause and remediation.
- Playing CTFs on TryHackMe, and moving into HackTheBox and cloud security.

### Focus areas

- Web application exploitation (SQLi, SSTI, insecure deserialization, auth bypass)
- Network attacks (BGP prefix hijacking, DNS interception and exfiltration)
- AI / LLM security (prompt injection, model supply chain)
- Cloud security (AWS, Azure)
- Privilege escalation and post-exploitation
